# ParkinSight

# Parkinson’s Disease Multiview Proteomics Clustering

## 1. Initial Setup

Create the following folder structure:

```text
ParkinSight/
├── README.md
└── Datasets/
    ├── Raw/
    │   ├── PPMI_Curated_Data_Cut.xlsx
    │   ├── 9000_CSF_Data.xlsx
    │   └── 9000_Plasma_Data.xlsx
    └── Processed/
        └── MultiView/
            ├── processed_views/
            ├── kernels/
            ├── cluster_assignments/
            ├── metrics/
        └── SingleView/
```

- **Raw:** Contains the three original source files: the curated data list, Project 9000 CSF proteomics, and Project 9000 plasma proteomics.
- **Processed:** Stores cleaned datasets and analysis outputs generated by the scripts.

The code should read the raw files from `Datasets/Raw/` and save generated outputs under `Datasets/Processed/`. Check the path definitions in the script to ensure they match this structure.

## 2. Project Goal

Identify potential Parkinson’s disease subtypes by integrating three baseline data views:

- Clinical characteristics
- CSF proteomics
- Plasma proteomics

The goal is to discover participant groups and later evaluate their relationships with polygenic risk scores (PRS), alpha-synuclein seed amplification assay (SAA) status, and longitudinal MoCA decline.

## 3. What the Code Does

Run code files from project directory in their numerical order, starting with 01. 

The multiview integration script:

1. **Loads and aligns data:** Matches participants across clinical, CSF, and plasma datasets using participant identifiers and retains the shared cohort.
2. **Preprocesses features:** Handles missing values, removes all-missing and constant protein features, imputes remaining missing values using medians, and standardizes features.
3. **Builds similarity kernels:** Creates an RBF similarity matrix for each data view.
4. **Integrates views:** Combines the three kernels using equal weights and alternative weighting schemes.
5. **Clusters participants:** Applies spectral clustering for different cluster counts and evaluates silhouette scores and cluster sizes.
6. **Evaluates consistency:** Uses the adjusted Rand index (ARI) to compare cluster assignments across weighting schemes.
7. **Saves outputs:** Stores processed views, kernels, cluster assignments, metrics, and metadata in `Datasets/Processed/MultiView/`.

## 4. Current Results

The current analysis aligned **206 participants**.

- CSF-only clustering achieved the highest tested silhouette score: approximately **0.282** with two clusters.
- Equal-weight multiview clustering achieved a silhouette score of approximately **0.153** with two clusters.
- CSF-dominant weighting improved the combined score to approximately **0.203**.
- Two-cluster assignments were identical across equal-weight, CSF-dominant, and CSF-plus-clinical weighting schemes (ARI = 1.0).
- Excluding plasma produced highly similar assignments (ARI ≈ 0.961).

These results suggest that the two-cluster solution is robust to the weighting choices tested so far. However, stability under participant resampling and biological validation remain outstanding.
